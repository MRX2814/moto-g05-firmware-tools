# Pomoc i zgłaszanie problemów

Najpierw sprawdź [FAQ](docs/faq.md) i odpowiednią instrukcję. Jeśli problem nadal występuje, utwórz Issue.

Podaj model i wariant telefonu, wersję Androida, numer kompilacji, stan bootloadera, objaw, wykonane kroki oraz komunikat błędu.

Nie publikuj haseł, tokenów, numeru IMEI, numeru seryjnego ani danych konta Google.
