# Odblokowanie bootloadera

`DRAFT` — opis będzie zawierał oficjalną procedurę Motoroli dla właściwego wariantu Moto G05.

Odblokowanie bootloadera może wyzerować telefon i zmienić status zabezpieczeń. Przed rozpoczęciem wykonaj kopię danych i upewnij się, że masz dostęp do konta potrzebnego do oficjalnego uzyskania kodu odblokowania, jeśli jest wymagany.
